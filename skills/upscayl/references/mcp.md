# Connect from another PC

Fetch `/manifest.json` at the server address the user supplied. For a bare hostname or IP with a port, start with HTTP. Preserve an explicit HTTPS origin. Use the advertised `mcp` URL and `transport` in the client, `uploads` for file transfer and `skills.client.url` if a skill is wanted. A bootstrap IP may advertise a different LAN DNS name; the client must be able to resolve it. Existing connections can start with `list_models`.

- Check `tls.enabled`. For HTTPS use `tls.url` and read its manifest for HTTPS connection commands. If `tls.ca` is present, fetch its public certificate using `tls.ca.url` and verify the downloaded certificate’s SHA-256 fingerprint against the fingerprint the host operator sees at startup or in macOS service status before trusting it in the client or agent runtime. If the private CA is not yet trusted, the operator can share the HTTP setup URL and supply the fingerprint separately. If HTTPS is enabled without a CA download, use the device’s existing trust or obtain the public CA from its operator.
- Register the MCP URL with any client that supports Streamable HTTP. For Codex or OpenCode, the manifest also includes a ready-to-use command or config entry. Agents that read SKILL.md can optionally install the self-contained ZIP in their skills directory.
- Upload bytes as application/octet-stream: `curl --fail --data-binary "@photo.png" -H "Content-Type: application/octet-stream" "$UPLOAD_URL"` (set `UPLOAD_URL` to `manifest.uploads`). Use curl.exe in Windows PowerShell. Read file_id from the JSON response.
- Use list_models or explain_upscale if needed. Call upscale with file_id and options, e.g. `{"file_id":"...","options":{"scale":2,"format":"png"}}`. For a batch call upscale_batch with file_ids and common options. Preserve the input order when mapping jobs to filenames.
- Poll get_job with job_id, initially once a second then less often during long runs. If done, GET the result path on the same server with curl --fail --output and verify dimensions locally. The finished job also includes a comparison path with a slider and lens; this URL lasts only until expires_at, so save results locally and compare local files for longer viewing. If failed, report the error. Use cancel_job to stop an unwanted job. Images travel as files, outside model context.
- The server schedules automatic deletion of job files, results and IDs five minutes after completion, failure or cancellation. Unused uploads expire five minutes after upload. Reads do not extend the deadline. A source shared by concurrent jobs is retained through the last job’s deadline. DELETE /jobs/{id} and DELETE /files/{id} can release copies sooner. A restart discards job IDs. Input files can be up to 32 MiB. Each intermediate image must fit within 96 megapixels and 32,768 pixels per side.
- For an ordinary remote file or folder, the remote CLI handles this entire upload, poll and save sequence with --server. Use this when MCP registration is unavailable or the user wants a shell command.

Use the server on the trusted home LAN.
